# Your True Doc — Dr. Sunaina, MBBS

Static website: natural hygiene, raw vegan / fruit recipes, health topics, video lectures, consultations.

## Pages
`index.html` · `about.html` · `learn.html` · `recipes.html` · `videos.html` · `contact.html`

## Edit content
All content lives in **`js/content.js`**:
- `SITE` — email, WhatsApp number, social links (replace the TODO placeholders)
- `RECIPES` — copy an entry to add a recipe
- `TOPICS` — health topics on the Learn page
- `COMBINING` — food combining chart
- `VIDEOS` — add the YouTube video ID to show a lecture

Photos: `assets/`.

## Publish free (GitHub Pages)
Settings → Pages → Source: GitHub Actions. Every push to `main` deploys automatically.
